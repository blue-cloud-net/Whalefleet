## 操作审计（主机作用域「事件」）

> 主菜单项与表格骨架已在 0.0.7 创建，功能**前移到 0.9.0**——因为远程 shell 与 AI 写操作都需要留痕。

## v1.0 不包含（明确非目标）

> 这些功能在 v1.0（0.x + 1.0.0）**范围内不做**：

- ❌ **Agent 模式**（目标主机部署轻量 Agent）→ 1.0.0 之后
- ❌ **OAuth / OIDC 登录**（含 LDAP / AD）→ 1.0.0 之后
- ❌ **多实例 + 外部数据库（PostgreSQL）** → 1.0.0 之后
- ❌ **一次性 exec API**（`POST /api/v1/hosts/{hostId}/containers/exec`） → 显式不做
- ❌ **一次性 stats API**（单次 `docker stats --no-stream`） → 显式不做
- ❌ **系统 prune**（一次清四类） → 不在 v1.0 范围；**资源级 prune 已在 0.6.0 交付**
- ❌ **应用模板**（App Templates 等价物）→ backlog `B-005`
- ❌ **GitOps：从 Git 仓库同步 Stack** → backlog
- ❌ **计划任务 / cron**（定期备份、定期 prune、定时重启）→ backlog
- ❌ **共享凭据管理（SSH / Git）、主机快照浏览** → backlog
- ❌ **SIEM 外发**（认证与活动日志流到 syslog / HTTP）、**告警渠道扩展**（Slack / Telegram / ntfy）→ backlog
- ❌ **Terraform Provider / CLI、危险操作二次确认策略、容器归属调整** → backlog
- ❌ **MCP 独立部署形态**（独立容器 / stdio 包）→ backlog
- ❌ **公开 demo 实例** → 1.0.0 之后再考虑
- ❌ **VitePress / Docusaurus 独立文档站点** → 0.x 与 1.0.0 不启动

> **操作审计日志已从本清单移出**——前移到 `0.9.0`。
